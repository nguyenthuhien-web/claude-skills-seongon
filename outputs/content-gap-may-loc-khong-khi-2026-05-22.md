## Content Gap #1: Room Size & Capacity Matching Framework

### Current State in SERP
- **Gap**: No comprehensive guide linking room dimensions to device specifications
- **Mention**: CellphoneS briefly mentions "room size" as a filter but provides no selection logic
- **Problem**: Buyers search "máy lọc không khí phòng bao nhiêu m²?" but get product listings instead

### Gap Opportunity
- **Intent**: Problem-solving (how-to select based on home size)
- **Format**: Interactive guide + specification matrix
- **Proposed Structure**:
  1. How to calculate room air changes per hour (ACH)
  2. Room size categories: 15-20m², 20-30m², 30-50m², 50m²+
  3. Recommended CADR values for each size
  4. Model-to-room mapping table
  5. Case studies: "Máy lọc nào phù hợp phòng 25m²?"
  
### SEO Advantage
- **Targeting**: Long-tail keywords with buying intent
  - "Máy lọc không khí cho phòng 20m2"
  - "Lựa chọn máy lọc dựa trên diện tích"
  - "CADR rating là gì"
  
- **Estimated Volume**: 100-500 searches/month (high intent)
- **Competition**: None in current top 10
- **Difficulty**: Low-Medium (editable with technical specs)
